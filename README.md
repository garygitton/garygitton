## How I Work

- **Rust-First Code Contracts:** I prefer Code-Design-First (using Rust as SSoT and generating TypeScript via typeshare) to accelerate development and prevent AI model hallucinations.
- **Zero-Cost Abstractions & Decoupling:** I structure systems using strict hexagonal architecture to keep domain logic pure and compile times extremely fast.
- **Leverage & Clarity:** I care about building commercially relevant, high-throughput systems and shipping useful software rather than overengineering.
